# 📖 Sobre o Projeto

Projeto desenvolvido como Trabalho de Conclusão de Curso da Formação ADVPL / Protheus.

O sistema tem como objetivo realizar o controle de fornecimento através de tabelas customizadas, validações, gatilhos e rotinas desenvolvidas em ADVPL utilizando recursos nativos do ERP TOTVS Protheus.

---

# 🎯 Objetivos

- Desenvolver cadastro de Controle de Fornecimento (ZZ1);
- Desenvolver cadastro de Ocorrências do Fornecedor (ZZ2);
- Criar validações dos campos;
- Implementar gatilhos (SX7);
- Criar biblioteca de funções em ADVPL;
- Utilizar tratamento de erros nas rotinas.

---

# 🛠️ Tecnologias

- ADVPL
- Protheus
- SIGACFG
- SmartClient
- DevStudio
